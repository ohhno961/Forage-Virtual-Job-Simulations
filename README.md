## 🔍 Project 1: ANZ Packet-Level Threat Hunting
**Objective:** Conducted a forensic investigation into a suspicious workstation suspected of unauthorized file access and data exfiltration.

### Key Accomplishments
**Network Forensics:** Analyzed corporate PCAP files to reconstruct an attacker's timeline and identify unauthorized image downloads.

**TCP Stream Carving:** Utilized Wireshark to follow TCP streams and extract HTTP payloads from raw network traffic.

**Artifact Extraction:** Successfully reconstructed files from hex data using HexEdit to validate the contents of exfiltrated data.

**Protocol Filtering:** Applied advanced filters to isolate traffic from the suspected host (192.168.43.19) and map lateral movement attempts.

## 💳 Project 2: Fraud Detection & Behavioral Analytics (Splunk)
**Objective:** Engineered a custom Splunk dashboard to identify and visualize fraudulent transactions based on demographic and behavioral indicators.

### Key Accomplishments
**Data Ingestion:** Transformed and ingested complex transactional datasets into Splunk Enterprise on a Kali Linux environment.

**Fraud Pattern Recognition:** Authored SPL queries to identify high-risk demographics, targeted merchants, and geographic origins of fraudulent activity.

**Time-Series Analysis:** Isolated temporal trends to determine if fraud activity correlated with specific seasons or times of day.

**Dashboard Engineering:** Built an executive-level SOC Dashboard to provide real-time visibility into fraud trends, enabling rapid decision-making for security teams.
